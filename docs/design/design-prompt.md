# Working Hub 디자인 프롬프트 (다크 + 미래공학 테마)

> **용도**: claude.ai(아티팩트)에 붙여넣어 다크+블루 미래공학 디자인 목업을 생성하기 위한 프롬프트.
> **워크플로우**: claude.ai에서 목업 HTML 생성 → 아티팩트 **Publish(게시)** → `claude.site/...` 공개 링크를 Claude Code에 전달 → Claude Code가 fetch하여 디자인 토큰(색·타이포·간격·그림자·컴포넌트 규격) 추출 → `theme.ts`/`globals.css`에 반영 → 단계적 적용(Phase 0 토큰 → 1 골격/랜딩/네비 → 2 내부 페이지).
>
> **확정 사항**: 랜딩=로그인 후 메인 홈 / 진행=단계적 / 적용 범위=전 페이지 + 향후 만들 프로그램까지.
>
> **정확도 순위**: 게시 링크(HTML) ≈ HTML 코드 붙여넣기 > 대화 공유 링크 > 스크린샷.

---

## 프롬프트 (아래 블록 전체를 복사해서 claude.ai에 붙여넣기)

````markdown
당신은 시니어 프로덕트 디자이너입니다. 한국 금융/자산관리 회사의 B2B 어드바이저용 업무 웹앱("Working Hub")을 **미래공학적(futuristic) 다크 테마**로 리디자인하는 디자인 시스템과 대표 화면들을 만들어 주세요.

# 제품 맥락
- 사용자: 금융 어드바이저(전문가). 데스크탑 우선(1440px 기준), 데이터가 많은 업무 도구.
- 기존 톤: 라이트 + Navy. → 이번에 다크 + 일렉트릭 블루의 프리미엄 테크 무드로 전면 전환.
- 한국어 UI. 데이터 표/차트가 많아 **가독성·명암 대비(WCAG AA)** 가 매우 중요.

# 디자인 철학 (레퍼런스: TEST IO 랜딩페이지)
- 다크네이비~블랙 배경, 선명한 일렉트릭 블루 강조색
- 큰 볼드 타이포 히어로, 넉넉한 여백, pill(둥근) 버튼
- 추상적인 3D 블루 리본/그라데이션 글로우 형태 (이미지 없이 CSS 그라데이션 + SVG로 표현)
- 미세한 글래스모피즘(반투명 카드 + blur), 부드러운 네온 글로우, 절제된 모션
- "신뢰감 있는 첨단 금융 테크" 느낌. 과한 네온/장난스러움은 금지.

# 컬러 출발점 (필요시 정교하게 다듬어 주세요)
- 배경 base: #0B1220, 한 단계 위 surface: #121A2B, 카드: #16203A
- 보더/디바이더: #243049
- 강조 블루: #2563EB (hover #3B82F6), 보조 시안 글로우: #38BDF8
- 텍스트: primary #F1F5F9, secondary #94A3B8, muted #64748B
- 상승/성공 #10B981, 하락/위험 #EF4444, 경고 #F59E0B

# 반드시 포함할 산출물 (한 페이지 HTML 안에 위에서 아래로 순서대로)
1. **디자인 토큰 시트**: 컬러 팔레트(역할별), 타이포 스케일(폰트/크기/굵기/행간), 간격 스케일, 라운드(radius), 그림자/글로우, 버튼·입력·카드 규격을 표/스와치로 시각화
2. **상단 가로 네비게이션 바**: 좌측 로고(Working Hub) + 가로 메뉴 + 우측 사용자아바타/설정/로그아웃. 활성 메뉴 강조 상태 포함
   - 메뉴 항목: 홈 / 고객 정보 관리 / 증권사 상품 관리 / 투자상품 관리 / Dr.GM 수당정산 / 증권사 수당정산 / 증권사 투자 상품 관리기 / Wrap 은퇴설계 / 주식·ETF 추천 / 콘텐츠 제작 / 설정
3. **메인 홈(로그인 후 첫 화면)**: 히어로 섹션(큰 카피 + CTA 버튼 2개) + 프로그램들을 카테고리별로 보여주는 카드 그리드(DATA관리 / 업무자동화 / 투자분석 / 콘텐츠제작). 미래공학적 그라데이션 배경 연출.
4. **대표 내부 업무 화면 1개(데이터 밀집형)**: 상단 필터 바(셀렉트·검색·읽기전용 정보 박스) + 데이터 테이블 + 라인차트(수익률/순자산 추이, 기간 버튼 3M/6M/1Y/MAX) — 다크 테마에서 표·차트가 어떻게 보이는지 정의

# 출력 형식 (중요)
- **단일 self-contained HTML 파일**. 외부 이미지/폰트 CDN 의존 최소화(시스템 폰트 또는 Google Fonts 1개까지 허용).
- 색/간격은 `:root` CSS 변수로 정의하고 그걸 참조 — 토큰을 그대로 추출할 수 있게.
- 데스크탑 1440px 기준 레이아웃. 반응형은 선택.
- 실제같은 더미 데이터(한국어, 금융 맥락)로 채워주세요.

먼저 디자인 방향(무드/팔레트) 요약을 2~3줄로 제안한 뒤, 위 4가지를 모두 담은 HTML을 출력해 주세요.
````

## 토큰 출발점 (현재 라이트 시스템 → 다크 매핑 기준)

현 시스템(`docs/planning/05-design-system.md`, `globals.css`)은 Navy `#1E3A5F` 기반 라이트.
다크 전환 시 추출 대상 토큰: 배경 3단계(base/surface/card), 보더, 강조 블루(+hover), 텍스트 3단계(primary/secondary/muted), semantic(success/danger/warning/info), radius, shadow/glow, 버튼·입력·카드 규격.
