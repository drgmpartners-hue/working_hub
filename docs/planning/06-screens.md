## 화면 상세

### SCR-01: 로그인
- **ID**: SCR-01
- **경로**: /login
- **기능**: 사용자 인증
- **컴포넌트**:
  - 로고 이미지
  - 이메일 입력 필드
  - 비밀번호 입력 필드
  - 로그인 버튼
  - 에러 메시지 영역
- **진입**: 앱 최초 접근, 세션 만료
- **이탈**: 로그인 성공 → 대시보드

### SCR-02: 대시보드
- **ID**: SCR-02
- **경로**: /dashboard
- **기능**: 모든 프로그램 접근 런처/허브
- **레이아웃**: 카테고리별 아코디언 + 카드 그리드 (화면 중앙)
- **컴포넌트**:
  - 공통 헤더 바
  - 카테고리 그룹 (업무 자동화 / 투자 분석 / 콘텐츠 제작)
  - 카테고리 클릭 시 하위 프로그램 카드 펼침
  - 프로그램 카드 (아이콘, 이름, 설명)
- **진입**: 로그인 성공, 헤더 홈 버튼
- **이탈**: 프로그램 카드 클릭 → 해당 프로그램 페이지 (새 페이지)

### SCR-03: Dr.GM 수당정산 계산기
- **ID**: SCR-03
- **경로**: /commission/dr-gm
- **기능**: 엑셀 업로드 → 수당 계산 → 명세서 다운로드
- **탭 구조**: 2탭
- **컴포넌트**:
  - 공통 헤더 바
  - **탭 1 (업로드 & 계산)**:
    - 엑셀 파일 업로드 영역 (상단)
    - 계산 결과 데이터 테이블 (하단)
    - "다음" 버튼
  - **탭 2 (미리보기 & 다운로드)**:
    - 개인별 수당명세서 미리보기
    - 다운로드 버튼
    - "이전" 버튼
- **진입**: 대시보드 → 업무 자동화 → Dr.GM 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

### SCR-04: 증권사 수당정산 계산기
- **ID**: SCR-04
- **경로**: /commission/securities
- **기능**: 웹 크롤링/엑셀 → 템플릿 적용/계산 → 보고서 다운로드
- **탭 구조**: 3탭
- **컴포넌트**:
  - 공통 헤더 바
  - **탭 1 (데이터 확인)**:
    - 크롤링 실행 버튼 or 엑셀 업로드 영역
    - 데이터 결과 확인 테이블
    - "다음" 버튼
  - **탭 2 (템플릿 & 계산)**:
    - 템플릿에 적용된 결과 표시
    - 계산 수행 / 결과 표시
    - "이전" / "다음" 버튼
  - **탭 3 (미리보기 & 다운로드)**:
    - 보고서 미리보기
    - 다운로드 버튼
    - "이전" 버튼
- **진입**: 대시보드 → 업무 자동화 → 증권사 수당정산 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

### SCR-05: IRP 포트폴리오 수익률 관리기
- **ID**: SCR-05
- **경로**: /portfolio/irp
- **기능**: 데이터 수집 → 분석/편집/AI → 보고서 PDF
- **탭 구조**: 3탭
- **컴포넌트**:
  - 공통 헤더 바
  - **탭 1 (데이터 확인)**:
    - 크롤링 실행 버튼 or 엑셀 업로드 영역
    - 데이터 결과 확인 테이블
    - "다음" 버튼
  - **탭 2 (템플릿 & 편집 & AI 분석)**:
    - 템플릿에 적용된 결과 표시
    - 직접 값 입력/수정 가능 영역 (리밸런싱, 추천상품)
    - AI 분석 결과 표시 영역
    - "이전" / "다음" 버튼
  - **탭 3 (보고서 & PDF)**:
    - 보고서 미리보기
    - PDF 다운로드 버튼
    - "이전" 버튼
- **진입**: 대시보드 → 투자 분석 → IRP 포트폴리오 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

### SCR-06: 주식/ETF 추천 프로그램
- **ID**: SCR-06
- **경로**: /investment/stock-recommend
- **기능**: 테마 분석/선택 → 종목 확인/포트폴리오 담기
- **단계 구조**: 2단계 (위저드)
- **컴포넌트**:
  - 공통 헤더 바
  - **Step 1 (테마 분석 & 선택)**:
    - 테마 목록 (증권사 API)
    - AI 분석 점수 표시
    - 추천 테마 하이라이트
    - 테마 바구니 담기 (복수 선택)
    - "다음" 버튼
  - **Step 2 (종목 확인 & 포트폴리오)**:
    - 선택 테마별 주식 목록
    - Top 5 구별 표시
    - 주식 상세 정보 (기간별 수익률, 기관 매수, 외국인 매수)
    - "내 포트폴리오에 담기" / "회사풀에 담기" 버튼 (SCR-10 연동)
    - "이전" 버튼
  - **팝업: 종목 상세 분석 (SCR-11)**:
    - 개별 주식/ETF 클릭 시 SCR-11 슬라이드업
    - 닫기 버튼
- **진입**: 대시보드 → 투자 분석 → 주식/ETF 추천 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

  - 승인/수정 버튼
  - 카드뉴스 미리보기 (브랜드 적용)
  - 텍스트 수정 → 재생성 기능
  - 이미지 부분 수정 요청 → 재생성 기능
  - 다운로드 버튼
- **진입**: 대시보드 → 콘텐츠 제작 → 카드뉴스 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

### SCR-10: 고객 포트폴리오 관리
- **ID**: SCR-10
- **경로**: /investment/portfolios
- **기능**: 고객별 포트폴리오 조회·관리, 배당·수익률 장기 추적
- **핵심 개념**: 배당형·성장형 종목을 장기 보유하여 안정적 현금흐름 창출
- **레이아웃**: 고객 선택 → 포트폴리오 선택 → 상세 뷰 (싱글 페이지 or 탭 구조)
- **컴포넌트**:
  - 공통 헤더 바
  - **고객 선택 영역**: 기존 고객 DB 검색/선택 드롭다운
  - **포트폴리오 목록 패널**: 해당 고객의 포트폴리오 카드 목록 (N개), 포트폴리오 추가/삭제 버튼
  - **포트폴리오 요약 섹션**:
    - 전체 투자금액, 예수금, 평가금액
    - 수익률 (배당 포함 / 미포함 토글)
  - **배당 현황 섹션**:
    - 예상 배당수익 현황 (월별 수령액 바 차트)
    - 예상 연간 배당 현황 (연간 합계, YoY 성장률)
  - **통합 차트 섹션**:
    - 투자 시작일~현재 각 종목 기준가 라인 차트 (종목별 색상 구분)
    - 수익률 흐름 오버레이 (배당 포함/미포함 토글로 전환)
  - **포트폴리오 구성 테이블**:
    - 컬럼: 종목명, 유형(배당형/성장형), 수량, 평균단가, 현재가, 평가금액, 수익률, 배당수익률
    - 종목 행 클릭 → SCR-11 슬라이드업/팝업
    - 종목 추가/삭제 버튼, FEAT-3-1 추천에서 담기 연동
- **진입**: 대시보드 → 투자 분석 → 고객 포트폴리오 카드 클릭
- **이탈**: 헤더 홈 → 대시보드

### SCR-11: 개별 종목 상세 분석 (팝업/슬라이드업)
- **ID**: SCR-11
- **경로**: (독립 경로 없음 — SCR-10 또는 SCR-06에서 팝업/슬라이드업으로 진입)
- **기능**: 주식 또는 ETF 개별 종목의 상세 분석 정보 제공
- **진입**: SCR-10 포트폴리오 테이블 종목 클릭 or SCR-06 Step 2 종목 클릭
- **닫기**: 팝업 닫기 버튼 or 슬라이드다운
- **타입 분기**: 주식(Stock) / ETF 여부에 따라 표시 섹션 다름

- **[공통] 헤더**:
  - 종목명, 티커, 현재가, 등락률, 타입 뱃지(주식/ETF)

- **[주식 타입] 컴포넌트**:
  - 기준가 차트: 이동평균선(5/20/60/120일) + 거래량 서브 차트
  - 밸류에이션 지표: PER, EPS, PBR
  - 수급 정보: 외국인 순매수 차트, 기관 순매수 차트 (기간 선택 가능)
  - 기업 정보: 업종, 시가총액, 주요 사업 요약
  - 수익 구조: 매출·영업이익 트렌드 (최근 4분기)
  - 관련 기업: 동일 업종 상위 종목 리스트

- **[ETF 타입] 컴포넌트**:
  - 기준가 차트: 이동평균선(5/20/60/120일) + 거래량 서브 차트
  - 포트폴리오 구성: 편입 종목 Top 10 비중 파이/바 차트
  - 편입 기업 분석: 주요 편입 종목별 비중·수익률
  - 배당 정보: 배당주기, 배당수익률, 배당안정성 지표, 배당성장성 지표

- **[추후 기획]**: 주식/ETF 타입별 화면 레이아웃 상세 설계 별도 진행
- **데이터 소스**: KIS API (primary) + 네이버 금융 (secondary fallback)
