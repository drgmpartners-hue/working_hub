# 차트 패턴 기반 매수·매도 신호 엔진 — 설계 보고서 v2

> **v1 → v2 변경 요지**: 전문가 검토에서 발견된 7개 치명적/중요 결함과 5개 보완사항을 반영.
> ① 스코어 정규화(도달 불가 밴드 해결) ② 패턴 탐지 알고리즘 명세 신설 ③ Regime/L1 역할 분리(이중 카운팅 제거) ④ 거래량의 필수 확인자 승격 ⑤ L7 분리(ORB 점수 / 격언 플래그) ⑥ 한국 시장 특수성(가격제한폭·VI·갭·비용) ⑦ L0 시장 컨텍스트 신설 ⑧ ATR 병행 손절 ⑨ 백테스트 캘리브레이션 로드맵 ⑩ 멀티 타임프레임 ⑪ 바닥권/천장권 정량 정의 ⑫ 설명가능성 JSON 필드.

---

## 0. 면책 및 설계 원칙

- 본 체계는 **확률적 경향치**이며 수익을 보장하지 않는다. 자동 신호는 사람의 최종 검토를 전제로 한다.
- 의사결정 순서 고정: **시장(L0) → 국면(Regime) → 신호(L1~L6) → 확인(거래량 필수) → 게이트/거부권 → 진입·청산 → 리스크**. 순서를 건너뛴 신호는 무효.
- 패턴은 이름이 아니라 **돌파 방향 + 거래량**으로 최종 판정한다.
- 모든 캔들 판정은 색이 아니라 **`close > open`(양봉) / `close < open`(음봉)** 으로만 한다. (한국 HTS 빨강=양봉, 서양식 녹색=양봉 — 색 기반 로직 금지)

## 2. 레이어 구조 (L0 + Regime + L1~L7 + G)

### 점수 체계 — 정규화 (v2 핵심 수정)

각 레이어는 `s ∈ [-1,+1]` 출력. **종합 스코어는 활성 가중치 합으로 정규화**:

```
Score = ( Σ active( wᵢ × sᵢ ) / Σ active( wᵢ ) ) × 100   ∈ [-100, +100]
```

- 스윙 모드에서 L7 비활성 → 분모에서도 제외되므로 모드 간 스케일 일관성 유지.
- 밴드 기준값(§5)은 **v1 임시값**이며, 백테스트 후 분위 기반으로 재캘리브레이션한다(§10 로드맵).

### 가중치 (활성 시)

| # | 레이어 | w | 역할 |
|---|---|---:|---|
| L1 | 추세 *질* (기울기·이격도) | 15 | 과열/되돌림 판정 |
| L2 | 차트 패턴 (확정된 것만) | 25 | 주 신호 |
| L3 | 지지·저항 위치 | 15 | 위치 |
| L4 | 캔들 (위치 조건부) | 15 | 트리거 |
| L5 | 거래량 | 12 | **필수 확인자** |
| L6 | 다이버전스 | 8 | 모멘텀 경고 |
| L7a | 장중 ORB (시가 기준) | 10 | 장중 모드만 |
| L7b | 장중 격언 (5대 공식 중 서사형) | 0 | **플래그만, 점수 0** |

L0(시장)·Regime(국면)·G(돌파 품질)는 점수가 아니라 **게이트/승수**로 작동한다.

---

### L0. 시장 컨텍스트 (신설) — 게이트

개별 종목 분석 전에 **지수에 동일 엔진(Regime 판정)을 먼저 적용**한다.

| 지수 국면 | 개별 종목 매수 신호 | 개별 종목 매도 신호 |
|---|---|---|
| 상승 추세 | ×1.0 | ×1.0 |
| 박스권 | ×0.85 | ×1.0 |
| 하락 추세/분배 | **×0.7** (숲이 불타는데 나무를 사지 않는다) | ×1.1 |

보조 지표(있으면): 상승종목비율 <40% 지속 시 매수 ×0.9 추가, USD/KRW 급등(5일 +2% 이상) 시 매수 ×0.9 추가. 누적 하한 ×0.6.

"지금 증시 상황" 질문에는 이 L0 판정(지수 국면 + 근거)이 답의 골격이 된다.

---

### Regime. 국면 판정 — MA *구조* 전담 (v2: L1과 역할 분리)

입력: MA **배열**(정/역배열), 골든/데드크로스 발생 여부, 박스 탐지(탐지 명세 §C-3), 대표 패턴 존재.

| 국면 | 식별 조건 | 기본 태도 |
|---|---|---|
| 분배/천장 | 정배열 와해 시작 + M형·H&S·다이아몬드천장 확정 | 비중 축소 |
| 하락 추세 | 데드크로스 + 5<20<60 + 계단식 하락 | 신규 매수 금지 |
| 박스권 | 박스 탐지 + 방향 미확정 | **강제 관망** |
| 축적/바닥 | 역배열 둔화 + W바닥·역H&S·하락쐐기 형성/확정 + 거래량 바닥 | 분할 매수 준비 |
| 상승 추세 | 골든크로스 + 정배열(5>20>60>120) + 20일선 지지 | 눌림목 매수 |

**게이트 규칙**
- 박스권 → 종합 스코어 무관 **강제 관망**. 박스 상/하단 거래량 동반 돌파 확정 시에만 해제.
- 하락/분배 국면의 매수 신호 ×0.5.
- 상승 국면의 지속형 매수 패턴(깃발·삼각형·눌림목) ×1.15.

**멀티 타임프레임 (v2 신설)**: 주봉으로도 Regime을 판정한다. **주봉 국면과 역방향인 일봉 신호는 액션을 한 단계 강등**(예: 매수→분할 매수). 주봉·일봉 동방향이면 강등 없음.

---

### L1. 추세 *질* — 기울기·이격도 (v2: 배열 판정 제거)

Regime이 "정배열인가"를 보고, L1은 "그 추세가 **건강한가, 과열인가**"를 본다. 이중 카운팅 제거.

| 상태 | s |
|---|---:|
| 20MA 기울기 양(+) & 이격도(20) ∈ [0%, +8%] — 건강한 추세 | +0.7 |
| 20MA 터치 눌림목 (이격도 0±2%, 기울기 양) — 생명선 매수 위치 | +0.9 |
| 이격도(20) > +12% — **과열** (추격매수 위험) | -0.5 |
| 이격도(20) < −12% — 과매도 (반등 후보, 단독 매수 금지) | +0.3 |
| 기울기 음 & 이격도 < 0 — 추세 훼손 | -0.7 |
| 골든크로스 *직후* 5봉 이내 (신선한 전환) | +0.8 |
| 데드크로스 *직후* 5봉 이내 | -0.8 |

> 효과: "정배열이지만 이격 +15% 과열" 상황에서 Regime은 우호적이어도 L1이 감점 → 천장 추격매수 차단.

---

### L2. 차트 패턴 — 확정(confirmed)된 패턴만 점수화

**탐지·확정 알고리즘은 별도 명세(탐지 명세 §B)를 따른다. 형성 중(forming) 패턴은 점수 0, `watch` 필드로만 보고** — 미래참조(lookahead) 차단.

매수(확정 시): 역H&S +0.9 / 삼중바닥 +0.8 / 컵앤핸들 +0.85 / 상승삼각형·상승깃발·페넌트 +0.8 / W바닥 +0.7 / 하락쐐기 상방돌파 +0.7 / 박스 상단돌파 +0.7

매도(확정 시): H&S −0.9 / M형(쌍봉) −0.9 / 삼중천장 −0.85 / 역V형 −0.8 / 하락삼각형·하락깃발 −0.8 / 상승쐐기 하방이탈 −0.7 / 다이아몬드천장 −0.6 / 박스 하단붕괴 −0.7

중립: 대칭삼각형·박스권·확장삼각형 = 0 (확장삼각형은 변동성 경고 플래그).

> 신뢰도 % → s 환산은 v1 캡 유지(100%→0.9). **v2 로드맵에서 백테스트 적중률로 교체**(§10).

---

### L3. 지지·저항 — v1 유지 (2회 이상 반응 레벨만)

지지 반등 +0.7 / **돌파 후 리테스트에서 옛 저항=지지 전환** +0.9 / 저항 거부(긴 윗꼬리) −0.7 / 지지 붕괴 −0.9 / 역할 전환 재테스트 성공 추세방향 +0.8.

---

### L4. 캔들 — 위치 조건 *정량화* (v2 신설)

**바닥권** := `close ≤ 60봉 최저가 × 1.10` **또는** `RSI(14) < 35`
**천장권** := `close ≥ 60봉 최고가 × 0.90` **또는** `RSI(14) > 65`

- 반전 매수 캔들(망치형, 상승장악형, 관통형, 샛별, 적삼병, 상승형도지)은 **바닥권에서만** s 부여. 위치 미충족 → s=0.
- 반전 매도 캔들(유성형, 흑운형, 석별, 흑삼병, 교수형)은 **천장권에서만** s 부여.
- 단일 캔들·조합별 s 값과 기하 정의(몸통/꼬리 비율)는 탐지 명세 §D 표를 따른다. (★4=±0.9, ★3=±0.65, ★2=±0.4)
- **상한가/하한가/VI 발동일은 L2·L4 점수 무효(s=0)** — 호가 왜곡으로 캔들·패턴 해석 불가(v2 한국 시장 규칙).

---

### L5. 거래량 — **필수 확인자** (v2 승격)

점수 기여(w=12)에 더해, **매수/매도 신호 확정의 전제 조건**이다(§4 Confluence).

| 상황 | s |
|---|---:|
| 돌파봉 거래량 ≥ 2.0 × vol_avg20 | 신호방향 +0.9 |
| 돌파봉 거래량 ≥ 1.5 × | +0.7 |
| 신고가인데 거래량 감소 | -0.4 |
| 가격↑ + 거래량 못 따라옴 (5봉 추세 비교) | -0.5 |
| 돌파봉 거래량 < 1.2 × | **거부권** (가짜 돌파 의심) |

---

### L6. 다이버전스 — v1 유지

A형 ±0.6 / B형 ±0.4 / C형 ±0.2. 단독 매매 금지 — L2~L4 중 1개 이상 동방향일 때만 점수 인정, 아니면 플래그만.

---

### L7. 장중 — 분리 (v2)

**L7a. ORB / 시가 기준 (w=10, 정량 판정)** — 장 시작 30분 법칙의 정량화:

| 30분 종료 시점 판정 | s |
|---|---:|
| 30분 범위 ≤ 0.5×ATR(일중 환산) — 무동 | 0.0 |
| 상승 후 하락, **현재가 < 시가** | -0.6 |
| 상승 후 하락, **현재가 ≥ 시가** (시가 사수) | +0.6 |
| 하락 후 반등, **현재가 > 시가** (시가 탈환) | +0.7 |
| 하락 후 반등, 현재가 < 시가 | -0.5 |
| 오전 계단식 하락 (연속 박스 하향) | **거부권** |

**L7b. 격언 플래그 (w=0, 점수 기여 없음)** — 공식 1(오후 급등=유인 의심), 공식 3(오전 급락=흔들기 가능), 공식 4(급등 후 안착 실패=소모) 등은 반증 불가 서사이므로 `lore_flags` 배열로만 출력. 백테스트로 유의성 확인 시 v3에서 가중치 부여 검토.

---

### G. 돌파 품질 — v1 유지 + 정량화

진짜: 거래량 조건(L5) 충족 + 되돌림 깊이 ≤ 돌파폭의 50% + 옛 저항 위에서 지지 → 점수 ×1.2 (캡 ±100).
가짜: 거래량 미달 **또는** 종가 기준 박스/패턴 내부로 회귀 → 해당 방향 점수 0, 관망.

## 3. Confluence 요건 (v2 강화)

v1의 "아무 레이어 2개"는 필터 역할을 못 한다. v2 확정 조건:

```
매수 확정 = [ L2(확정 패턴) 또는 L3(위치) 중 ≥1개 동방향 ]
          AND [ L5 거래량 확인 충족 ]   ← 필수
          AND [ 그 외 레이어 ≥1개 동방향 ]
매도 확정 = 대칭 (단, 보유 청산은 L5 면제 가능 — 리스크 관리 우선)
```

거래량 확인이 없으면 점수가 아무리 높아도 `WATCH`(관심)로 강등.

---

## 4. 거부권(Veto) 총람

1. Regime=박스권 & 방향 미확정 → 관망
2. 돌파봉 거래량 < 1.2×평균 → 해당 신호 무효
3. 돌파 후 종가 기준 패턴 내부 회귀 → 속임수, 관망
4. 손절선 정의 불가 → 진입 무효
5. 장중: 오전 계단식 하락 / 시가 하향 이탈 상태
6. 확장삼각형 등 변동성 급확대 → 신규 진입 자제
7. **당일 상한가·하한가·VI 발동 → L2·L4 무효, 신규 진입 보류** (v2)
8. `data_quality: degraded` → 액션 한 단계 보수화 (v2)

## 5. 종합 스코어 & 의사결정 밴드

파이프라인: `L0 게이트 → Regime 게이트 → Σ정규화 스코어 → G 승수 → Regime 승수 → L0 승수 → Confluence 검증 → Veto → 주봉 정렬 강등 → 밴드`

| 정규화 스코어 | 액션 | 비고 |
|---:|---|---|
| ≥ +60 | 강력 매수 | 분할 진입 시작 |
| +35 ~ +60 | 매수 | |
| +15 ~ +35 | 분할 매수/관심(WATCH) | |
| −15 ~ +15 | 관망 | |
| −35 ~ −15 | 비중 축소 | |
| −60 ~ −35 | 매도 | |
| ≤ −60 | 강력 매도 | |

> v2에서 밴드 경계를 70→60으로 하향: 정규화 후 현실적 강세 시나리오(검산 시 +60대)가 최상위 밴드에 도달 가능해야 한다. **이 값도 임시이며 §10 캘리브레이션 대상.**

## 6. 리스크 관리 오버레이

- **손절 = 두 기준 중 진입가에 가까운(보수적인) 쪽**: ① 구조 기준(직전 스윙 저점/지지 하단/패턴 무효화점) ② **진입가 − 2×ATR(14)** (v2 병행).
- 1회 손실 ≤ 총자본 1~2% → 수량 역산: `수량 = (자본×위험%) ÷ (진입가−손절가)`.
- 손익비 최소 1:2 — **거래비용 차감 후 기준**(v2): 목표가 산정 시 매도 시 증권거래세(코스피 0.05%+농특세, 코스닥 0.15% — 2026년 기준 변동 가능, 사용 시점 세율 확인) + 수수료 + 슬리피지 가정 0.1%를 반영.
- **갭 리스크 규칙**(v2): 손절가를 갭으로 건너뛴 경우 시가 즉시 집행, 한도 초과 손실분은 `gap_loss` 필드에 기록하고 당일 신규 진입 1회 제한.
- 분할 매수·분할 매도 원칙.

## 9. 충돌·모호성 처리 (v1 유지 + 보강)

1. **쐐기 방향**: 클래식 TA 우선(상승쐐기=약세 경향, 하락쐐기=강세 경향)이되 `breakout_direction` + 거래량이 최종 판정.
2. 신뢰도 % = 경향치, s 캡 ±0.9.
3. 캔들 위치 의존성 → §L4 정량 정의로 강제.
4. 박스권 50% = 관망 명령(점수화 금지).
5. L7은 분봉 존재 시에만 활성, 정규화 분모에 자동 반영.
6. **캔들 색 ≠ 방향**: 항상 `close vs open` 비교(v2).
