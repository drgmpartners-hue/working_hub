# 기업 리포트 알림톡 템플릿 (SOLAPI 심사 신청용) — 2차 신청안

- 채널: 기존 회사 카카오 채널(SOLAPI_PF_ID)
- 분류: **사내 업무 알림**(수신자 = 골드마운틴파트너스 임직원). 광고·홍보 문구 없음
- 심사 승인 후 **기업 리포트 > 발송 설정**에 템플릿 ID를 입력한다. 입력 전에는 같은 내용이 LMS로 나간다.
- 1차 반려(2026-09) 사유: "수신 대상을 명확히 확인하기 어려움 — 사내 관리자(임직원) 대상인지, 어떤 상황·액션으로 발송되는지 기재 요청"
  → 2차안: 첫 줄 `[사내 업무용 메시지]`, 수신자 이름 `#{담당자명} 담당자님`, 발송 사유 문장을 본문에 넣음
- 알림톡 본문은 변수를 채운 뒤 **1,000자 이내**. 코드의 변수 상한(초과 시 "…"로 자름):
  `#{종합브리핑}` 230자, `#{기업별요약}` 330자(상위 5개 기업), `#{날씨}` 60자, `#{전일증시}` 130자(2줄) → 최대 약 970자

## 템플릿 B — 데일리 (코드명: daily)

- 템플릿 이름: `사내_투자기업_데일리브리핑`
- 메시지 유형: 기본형 / 강조 유형: 선택 안 함

```
[사내 업무용 메시지]
#{담당자명} 담당자님, 오늘의 투자기업 데일리 브리핑이 준비되었습니다.

본 메시지는 사내 업무 시스템(Working Hub)에 투자기업 브리핑 수신자로 등록된 임직원께 평일 오전 발송되는 업무 알림입니다.

■ 기본정보
#{날짜} | #{날씨}
#{전일증시}
대상 #{기업수}개 기업 · 기사 #{기사수}건 · 주의 #{주의수}건

■ 종합브리핑
#{종합브리핑}

■ 기업별 브리핑
#{기업별요약}

전체 기사와 원문 링크는 아래 버튼에서 확인해 주세요.
```

- 버튼(WL) 이름: `브리핑 보기`
- 링크(모바일·PC): `https://working-hub.vercel.app/content/company-report/briefing?date=#{날짜코드}`
- 변수 예시(심사 신청 화면의 '변수 예시' 칸):
  - `#{담당자명}` = `김민호`
  - `#{날짜}` = `9/28(월)`
  - `#{날씨}` = `서울 오전 맑음 / 오후 구름많음, 14~25℃, 강수확률 20%`
  - `#{전일증시}` = `미 S&P500 5,812.4(+0.4%) 나스닥 18,920.1(+0.7%)` 줄바꿈 `한 코스피 2,650.3(+0.9%) 코스닥 780.2(-0.3%)`
  - `#{기업수}` = `6`, `#{기사수}` = `12`, `#{주의수}` = `1`
  - `#{종합브리핑}` = `- A사 시리즈B 투자 유치 보도` 줄바꿈 `- B사 신제품 출시 발표`
  - `#{기업별요약}` = `· A사: 시리즈B 150억 투자 유치` 줄바꿈 `· B사 [주의]: 대표 교체 공시`
  - `#{날짜코드}` = `2026-09-28`

## 템플릿 C — 월간 (코드명: monthly, P3에서 발송 연결)

- 템플릿 이름: `사내_투자기업_월간브리핑`

```
[사내 업무용 메시지]
#{담당자명} 담당자님, #{월} 투자기업 월간 브리핑이 준비되었습니다.

본 메시지는 사내 업무 시스템(Working Hub)에 투자기업 브리핑 수신자로 등록된 임직원께 매월 초 발송되는 업무 알림입니다.

■ #{월} 요약
#{월간요약}

■ 주목할 기업
#{주목기업}

■ 주의가 필요한 기업
#{주의기업}

■ 다음 달 체크포인트
#{체크포인트}

기업별 정리와 고객 상담 참고 사항은 아래 버튼에서 확인해 주세요.
```

- 버튼(WL) 이름: `월간 브리핑 보기`
- 링크: `https://working-hub.vercel.app/content/company-report/briefing?month=#{월코드}`
- 길이 상한(코드에서 자름): 요약 220자, 주목 기업 220자, 주의 기업 130자, 체크포인트 130자 (고정 문구 약 230자 → 최대 약 950자)
- 변수 예시: `#{담당자명}`=`김민호`, `#{월}`=`9월`, `#{월코드}`=`2026-09`, 나머지는 한두 줄 예시 문장

## 검수 담당자 답변(SOLAPI 문의/재검수 요청 칸에 붙여넣기)

```
안녕하세요. 반려 사유 확인하였고 아래와 같이 답변 및 수정드립니다.

1. 수신 대상: 당사(골드마운틴파트너스) 임직원입니다. 외부 고객이나 불특정 다수에게는 발송하지 않습니다.
2. 발송 상황: 사내 업무 시스템(Working Hub)에서 관리자가 '투자기업 브리핑 수신자'로 등록한 임직원(2~5명)에게만, 평일 오전(데일리) 및 매월 초(월간) 업무 보고용으로 발송됩니다. 수신자 등록·해제는 사내 시스템에서 관리하며 해제 즉시 발송이 중단됩니다.
3. 메시지 수정: 본문 첫 줄에 [사내 업무용 메시지]를 표기하고, '#{담당자명} 담당자님'으로 수신자 이름을 넣었으며, 발송 사유 문장(수신자로 등록된 임직원께 발송되는 업무 알림)을 본문에 기재하였습니다.
4. 광고·홍보 내용은 포함되지 않으며, 당사가 관리하는 투자기업 관련 뉴스 요약을 사내 담당자에게 전달하는 정보성 업무 알림입니다.

재검수 부탁드립니다. 감사합니다.
```

```
본 메시지는 사내 업무 시스템(Working Hub)에 브리핑 수신자로 등록된 임직원께 발송되는 업무 알림입니다.

투자기업 #{기업수}곳에서 기사 #{기사수}건(주의 #{주의수}건)이 확인되었습니다.
아래 버튼에서 브리핑을 확인해 주세요.
```
