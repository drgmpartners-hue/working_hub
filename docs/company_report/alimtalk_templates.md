# 기업 리포트 알림톡 템플릿 — v2(본문에 기사 링크, 2026-09-29)

**왜 v2인가:** v1은 '브리핑 보기' 버튼이 Working Hub 웹 화면을 열어서, 폰에서는 로그인·화면 크기 때문에 보기 어렵다.
v2는 카톡 본문만 읽고 끝나도록 요약 문장 끝에 [1][2] 번호를 달고, 맨 아래에 번호별 짧은 기사 링크를 넣는다. 버튼은 없다.

- 짧은 링크: `https://working-hub.vercel.app/r/코드` → 로그인 없이 원문 기사로 바로 이동(Working Hub 내부 정보는 드러나지 않음)
- 알림톡은 변수를 채운 뒤 1,000자 이내여야 해서, 코드가 기업 수·문장 길이를 자동으로 줄인다(링크는 보통 5~8개)
- 템플릿 ID를 비워 두면 **같은 내용이 문자(LMS)로** 나간다. 문자에서도 링크는 눌린다 → v2 승인 전까지는 ID를 비워 두는 것을 권장
- v1 ID를 그대로 두면 v1 형식(링크 목록 없음)과 변수가 맞지 않아 실패할 수 있다(실패 시 문자로 대체 발송)
